# 🏜️ MANGYSTAU GO

### Smart tourism & safety platform for Mangystau

**MANGYSTAU GO** — цифровая платформа для туристов и жителей Мангистау, которая объединяет туристические места, планирование поездок, поиск попутчиков, групповые чаты и информацию о безопасности.

> **Не просто «куда поехать?», а «как туда добраться, с кем поехать и безопасно ли ехать сейчас?»**

---

## 🎯 Problem

Мангистауская область обладает большим туристическим потенциалом, однако самостоятельным туристам приходится искать информацию в разных источниках:

- как добраться до туристического объекта;
- какой транспорт выбрать;
- сколько будет стоить поездка;
- где найти попутчиков;
- какие группы уже собираются;
- безопасно ли посещать место сейчас;
- есть ли предупреждения о погоде или других рисках.

MANGYSTAU GO объединяет эти сценарии в одном цифровом сервисе.

---

## 💡 Solution

Платформа объединяет:

- 🗺️ туристические места;
- 🚗 планирование поездок;
- 👥 поиск попутчиков;
- 💬 групповые чаты;
- 🛡️ информацию о безопасности;
- 🚨 экстренный вызов 112;
- 📊 туристическую аналитику;
- 🌐 казахский, русский и английский языки.

---

## 🚀 Main Features

### 🗺️ Explore

Пользователь может посмотреть туристические места Мангистау:

- Bozzhyra
- Tamsaly
- Saura
- Sherkela

Для каждой локации отображается информация и координаты.

---

### 🧭 Smart Trip

Пользователь выбирает:

- туристическое место;
- количество дней;
- бюджет;
- транспорт;
- количество людей.

Система рассчитывает параметры поездки и позволяет сохранить её.

---

### 👥 Go Together

Пользователь может:

- создать группу;
- найти существующую группу;
- присоединиться к поездке;
- разделить транспортные расходы;
- найти попутчиков.

Это особенно важно для туристов без собственного автомобиля.

---

### 💬 Chats

После вступления в группу пользователь получает доступ к её чату.

Возможности:

- список групп пользователя;
- отдельный чат каждой группы;
- отправка сообщений;
- отображение участников;
- обновление сообщений.

Сообщения сохраняются в PostgreSQL.

---

### 🛡️ Caspian Watch

Модуль безопасности отображает:

- погодные условия;
- ветер;
- порывы ветра;
- состояние волн;
- уровень риска;
- официальные предупреждения;
- опасные или ограниченные зоны.

Уровень риска:

🟢 Low  
🟡 Attention  
🟠 Elevated  
🔴 High  
🚫 Prohibited

---

### 🚨 SOS

В интерфейсе предусмотрена кнопка экстренной помощи.

Для чрезвычайных ситуаций используется официальный номер:

**112**

---

### 📊 Tourism Intelligence

Административная часть платформы может использовать агрегированные данные для анализа:

- туристического потока;
- популярных мест;
- групповых поездок;
- транспортного спроса;
- активности пользователей;
- зон повышенного риска.
